# LaTeX Guard - LaTeX 编译防错与排版质量守护技能

[![GitHub stars](https://img.shields.io/github/stars/cghggchg765-create/latex-guard)](https://github.com/cghggchg765-create/latex-guard)

## 简介

LaTeX Guard 是一个面向 OpenCode/Claude 的智能技能，专为 LaTeX 论文撰写提供全流程编译防错与排版质量保障。无论你是使用 NEU-Thesis、北大模板还是其他中文学位论文模板，该技能都能帮你系统性避免常见的 LaTeX 编译陷阱。

## 核心功能

- 🔍 **编译错误快速诊断**：7类常见编译错误（列对齐、溢出、浮动体跨页、公式分离、孤行、空白页、引用未解析）
- 📊 **表格排版规范**：标准模板、单元格换行、脚注嵌入、公式单元格
- 🎯 **12类PDF排版质量检测清单**：从封面到参考文献的逐项检查
- ⚡ **一键检查脚本**：PowerShell 5步批量扫描
- 🔄 **自我完善机制**：自动累积新发现的错误模式和解决方案

## 安装

1. 下载 `latex-guard.skill` 文件
2. 放入 `~\.agents\skills\latex-guard\` 目录
3. 重启 OpenCode/Claude 即可生效

## 适用场景

- 中文/英文学位论文（硕博）
- 学术期刊论文投稿
- LaTeX 模板开发与调试
- 团队协作中的编译规范检查
